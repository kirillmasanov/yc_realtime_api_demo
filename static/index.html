Возможности Realtime API

  • Голосовой диалог в реальном времени – низкие задержки, двунаправленный канал, потоковая передача взаимодейсивия
  • Voice Activity Detection (VAD) – авто-определение конца фразы
  • Автоматический вызов встроенных инструментов: web_search, file_search, mcp
  • Совместимость с OpenAI Realtime API
  • Совместимость с сервисом SpeechKit (поддержка общедоступных и уникальных голосов)
  • Поддержка памяти (Short-memory в рамках сессии)

План тестирования

  1. Базовый диалог. Скажите «Привет, как дела?» – ассистент должен ответить голосом и текстом.
  2. Калькулятор. «Посчитай 137 умножить на 48» – пользовательский (а не встроенный) tool.
  3. Веб-поиск. «Найди последние новости про ИИ» – Yandex выполняет поиск на своей стороне.
  4. Поиск по документу. Прикрепите файл через скрепку, дождитесь зелёного значка и задайте конкретный вопрос по содержимому - например, «найди в документе упоминания …» или «что сказано про …».
  5. VAD – паузы. Говорите с паузами внутри фразы – ассистент не должен прерывать раньше времени.
  6. Прерывание. Начните говорить пока ассистент отвечает – воспроизведение должно остановиться.
  7. Настройки. В ⚙️ смените голос на Дашу, попробуйте разные амплуа, выберите язык распознавания, режим ответа или измените системный промпт – нажмите «Применить».
  8. Другой язык. Переключите язык распознавания на English, спросите что-нибудь по-английски – модель ответит на английском.
