Особенности Realtime API в Yandex Cloud

  • Голосовой диалог в реальном времени – задержка <500 мс
  • Voice Activity Detection (VAD) – авто-определение конца фразы
  • Инструменты: calculator (сервер), web_search (Yandex)
  • RAG – поиск по загруженному документу через search_index
  • PCM16 аудио, 44100 Hz, моно, base64 в JSON
  • Совместим с OpenAI Realtime API по протоколу
  • Голоса: Маша, Даша

План тестирования

  1. Базовый диалог. Скажите «Привет, как дела?» – ассистент должен ответить голосом и текстом.
  2. Калькулятор. «Посчитай 137 умножить на 48» – tool use на сервере, результат появится карточкой в чате.
  3. Веб-поиск. «Найди последние новости про ИИ» – Yandex выполняет поиск на своей стороне.
  4. Поиск по документу. Прикрепите файл через скрепку, дождитесь зелёного значка, спросите «о чём этот документ?».
  5. VAD – паузы. Говорите с паузами внутри фразы – ассистент не должен прерывать раньше времени.
  6. Прерывание. Начните говорить пока ассистент отвечает – воспроизведение должно остановиться.
  7. Настройки. В ⚙️ смените голос на Дашу, измените системный промпт, нажмите «Применить».
  8. Другой язык. Спросите что-нибудь по-английски – модель ответит на языке запроса.
