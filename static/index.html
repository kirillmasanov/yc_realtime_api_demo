Особенности Realtime API

  • Голосовой диалог в реальном времени — задержка <500 мс
  • Voice Activity Detection (VAD) — авто-определение конца фразы
  • Tool use — инструменты выполняются на сервере
  • PCM16 аудио, 44100 Hz, моно, base64 в JSON
  • Совместим с OpenAI Realtime API по протоколу
  • Голоса: Маша, Даша
  • web_search — выполняется на стороне Yandex

План тестирования

  1. Базовый диалог Скажите «Привет, как дела?» — ассистент должен ответить голосом и текстом
  2. Калькулятор «Посчитай 137 умножить на 48» — проверяет tool use на сервере
  3. Веб-поиск «Найди последние новости про ИИ» — использует web_search на стороне Yandex
  4. VAD — паузы Говорите с паузами внутри фразы — VAD не должен обрывать раньше времени
  5. Прерывание Начните говорить пока ассистент отвечает — воспроизведение должно остановиться
  6. Голос и промпт В ⚙️ смените голос на Дашу, измените системный промпт, нажмите «Применить»
  7. Английский Спросите что-нибудь по-английски — модель отвечает на языке запроса
