Требуется сделать веб-приложение, которое показывает функциональность Realtime Api от Яндекс Клауд. 
Ссылки на документацию:
https://aistudio.yandex.ru/docs/ru/ai-studio/operations/agents/create-voice-agent.html
https://aistudio.yandex.ru/docs/ru/ai-studio/concepts/agents/realtime.html#realtime-api

Приложение должно быть написано на fastapi с использованием uv для менеджмента пакетов.

В файле .env находятся переменные, которые нужны для работы приложения:
YANDEX_API_KEY=<ваш api key>
YANDEX_FOLDER_ID=<ваш folder id>
Ты не можешь читать данный файл, он секретный.

Приложение должно выглядеть в виде чата с кнопкой микрофона при нажатии на которую я могу отправить текстовое сообщение по моему голосу. 
Если у тебя есть вопросы по функциональности или по работе, или по дизайну приложения, задавай мне эти вопросы.

Используй openia api для realtime api, вот ссылки на документацию:
https://aistudio.yandex.ru/docs/ru/ai-studio/clientEvents/index.html
https://aistudio.yandex.ru/docs/ru/ai-studio/serverEvents/index.html
